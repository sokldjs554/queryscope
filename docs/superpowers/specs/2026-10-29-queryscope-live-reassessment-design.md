# QueryScope v4 재평가 설계

## 목적과 현재 승인 범위

사용자는 Codex에서 중단된 남은 작업을 이어서 수행하라고 요청했다. 이미 보완한 runtime-v4 입력 48개를 실제 평가할 수 있도록 구현·검증·고정하고, 기존 실제 응답 24건의 AI 의미 판정을 완성한다. 기존의 프로젝트·키 연결을 재사용하며 새 API 키를 만들지 않는다.

기존 사용자 조건은 새 유료 실험의 모델·대상·호출 수·예상 비용·지출 상한을 실행 전에 별도로 확인하는 것이다. 이전 v3 승인은 특정 준비물의 24회/$0.30에 한정됐고 모두 실행됐다. 현재 요청은 구현·검증을 계속할 권한이며 새 48회/$0.60에 대한 구체적인 승인을 기록한 발화는 아직 없다. 따라서 이번 단계에서 실제 API 호출이나 `approved=true` 기록은 하지 않는다. 유료 실행을 제외한 준비·검증·원격 CI를 모두 끝내고 마지막 승인만 남긴다.

## 선택한 구현 방식

이하의 구현 선택은 어시스턴트의 판단이다. 기존 v2/v3 실행기를 확장하면 과거 승인과 재현 경로를 건드리므로 새 실행 모듈을 둔다. 기존 OpenAI 어댑터와 24회 제한 Budget은 그대로 재사용한다. 하나의 새 캠페인 claim 아래 고정된 24회 원장 두 개를 조합해 총 48회와 $0.60을 제한한다. 각 실패/불확실 응답도 호출 한도를 소모하며 재시도·자동 재개는 없다.

## 고정 요구사항

- 기준 코드: `33c54ac2a20d0ec54d55e2b923217c6a9e749117`.
- 기존 `ko-search-clinic` 및 v1/v2/v3 기록, 승인, 예산, 원격 claim, 기존 실행기를 변경하지 않는다.
- 새 suite: `queryscope-v4-runtime`; 모델: `gpt-5.4-mini-2026-03-17`.
- 입력: v4 `run-v1/audit.json`의 `context_preparation.rows` 48개, T01~T24 × no_hint/hint. 원래 준비 payload 해시와 현재 재구성이 같아야 한다.
- 최대 48회, 회당 예약 $0.0125, 전체 예약 상한 $0.60, 출력 최대 800토큰, 요청 최대 11,000바이트.
- 2026-10-29 공식 모델 가격 확인: 입력 $0.75/1M, 출력 $4.50/1M. 캐시 할인은 계산하지 않는다. 출처: https://developers.openai.com/api/docs/models/gpt-5.4-mini . 이 한도는 해당 실험의 예약 상한이며 세금·다른 계정 사용량의 총청구 상한은 아니다.
- 준비 파일은 모델·문맥·실제 전송 payload·전체 입력·사례쌍·원자료 SHA-256을 포함한다. 승인 파일의 해시와 내용이 모두 맞아야 실행된다.
- source 또는 준비물의 변조, 누락·중복 사례쌍, 다른 모델/지침/요청, 초과 크기, 빈 승인 담당자, 잘못된 상한은 키 조회·claim·네트워크 전에 거절한다.
- 키는 기존 GitHub Actions `OPENAI_API_KEY` 시크릿으로만 연결한다. 값은 읽어 출력하거나 저장하지 않는다. 시크릿 부재면 claim 전에 중단한다.
- 로컬 exclusive campaign 디렉터리와 원격 원자적 tag 생성으로 중복을 막는다. 이미 실행한 입력을 다른 경로나 새 runner에서 다시 실행하지 않는다.
- 원격 claim은 실행기 내부에서 반드시 획득한다. 별도 사전 명령의 실행 여부나 이미 존재하는 tag를 실행 권한으로 인정하지 않는다.
- 원응답과 응답ID·usage·오류는 평가 전에 저장한다. 평가 실패 시 응답을 잃지 않으며 complete=false로 유지한다.
- v4 전용 기록 클라이언트가 수신한 HTTP 본문을 기존 provider의 파싱 전에 저장한다. 불완전·거절·비정상 JSON·HTTP 실패도 수신한 원문과 usage를 보존한다. 요청 인증 헤더를 기록하지 않으며 반사된 실제 키 문자열은 제거하고 그 사실을 표시한다.
- 응답에서 실제 관측한 모델명과 새 고유 응답ID가 맞아야 채점한다. 누락·다른 모델·중복ID는 원문을 남기고 provenance_error로 중단한다. 공급자의 기본 모델값을 관측 증거로 사용하지 않는다.
- runtime validator를 먼저 거친 후보만 격리 엔진 gate로 보낸다. 기존 36질의와 v3 정답 있는 16질의의 회귀를 후보별로 기록한다.
- 기존 실제 24응답과 겹치는 24개만 짝 비교하고, 추가 24개는 별도 개발 자료 집계로 남긴다. 새 48건 전체와 옛 24건의 성공률을 직접 비교하지 않는다.
- AI 의미 평가는 reviewer_type=AI, not_independent_human_review로 기록한다. 사람이 작성하지 않은 판정·독립성·이름을 채우지 않는다.

## 완료 조건

실행기·CLI·원격 claim·일회성 워크플로의 무료 테스트가 통과하고 48개 준비물이 고정되며 원격 CI까지 확인된 상태에서 유료 승인 요청을 한다. 24건의 AI 의미 검토는 원자료와 연결된 다섯 축 판정·이유·불확실성으로 완성한다. 실제 새 모델 결과가 생기기 전에는 자소서·포트폴리오에 생성 품질 향상을 추가하지 않는다.
