# QueryScope 설계

알바천국 AI 개발 지원용 검색 진단·근거·수정안 검증 프로젝트. PR #2 전체 이력에서 분기하며 원본 저장소는 쓰지 않는다. 추가 유료 호출은 0회.

기존 Python/Kiwi/BM25/FastAPI 화면을 유지한다. 대안인 전면 재작성은 기존 결과와 비교하기 어렵고, 새 LLM 평가는 승인 예산이 없다. 따라서 저장 응답 분석 + 새로운 무료 검색 평가 + 검증기 강화로 진행한다. 구현 선택은 작업자의 판단이다.

새 24개 질의/정답/평가 기준을 먼저 커밋한다. 실행 뒤 수정에 쓰지 않으며 기존 결과와 분리한다. 힌트 제거의 검색 영향은 실행하고, 새 생성의 진단/의미/보류 성능은 미실행으로 표시한다. 원인 분류·인용 추적·의미 지지·수정 구조·효과를 구분한다.

아답터/백팩 수정은 관측 분해와 명시적 표준형을 바탕으로 두 단계 후보를 만든다. 단어 의미를 자동 확정하지 않으며 회귀 게이트를 유지한다. 잘못된 인용/복합어는 원문이나 원응답을 고치지 않고 차단 근거를 남긴다.

화면은 QueryScope 브랜드와 과거 응답 재생/새 로컬 생성/새 오프라인 평가를 구분한다. 의미 검토 필요를 표시한다. API 기본 생성 비활성, 기존 유료 캠페인은 새 저장소에서 재실행 불가.

검증 후 README·지원 문서에 실제 새 수치와 미확인 범위를 반영한다. 원격 생성 권한이 없으면 Git bundle과 코드 아카이브로 완성물을 보존하고 업로드 장애를 정확히 보고한다.
