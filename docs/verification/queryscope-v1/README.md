## 힌트 제거

새 24개 및 기존 12개 각각에서 질의/카탈로그/분석기/BM25 top3/본문 400자 상한은 동일하게 두고 관찰 문장만 바꿨다. 입력 전체와 해시·검색 ID를 `new_hint_ablation`, `legacy_hint_ablation`에 보존했다.

| 집합 | 채점 대상 | 힌트 hit@3 / MRR | 무힌트 hit@3 / MRR |
|---|---:|---|---|
| 새 질의 | 원인 계열 가설 있는 11개 | 11/11 / 0.8485 | 1/11 / 0.0303 |
| 기존 사례 | 원인 계열 라벨 있는 9개 | 8/9 / 0.8148 | 6/9 / 0.4444 |

신규 원인 가설은 분해 4개·표기 변형 4개·영한 혼용 1개·복합어 2개이다. 순수 synonym_gap 신규 사례는 없어 해당 계열의 새 일반화는 평가하지 못했다.

5개 원인 계열 전부에 붙은 일반 문서는 적중 정답에서 제외했다. 건강·범위 밖·unknown은 이 점수에서 제외했다. 힌트 조건에는 정답 방향을 암시하는 문구가 있으므로 이 결과는 누수 민감도 검사다. 무힌트 조건에서도 검색된 문서가 진단에 충분하다는 뜻은 아니다.

**새 LLM 진단 비교는 미실행**이다. 저장된 응답을 무힌트 입력의 응답처럼 재활용하지 않았다. `model_answer=null`, `generation_evaluation=not_run_no_paid_calls`로 기록했다. 4개 자료 부족 질의의 실제 모델 보류율도 미실행이다. 보류/패치 금지 등 검증기 계약은 별도 작성 fixture로 검사하며 이를 생성 성능으로 집계하지 않는다.

## 기존 실패와 수정

- **아답터:** 사전만 등록해도 어댑터 토큰과 이어지지 않아 0→0. 관측한 분해를 막고 운영자가 제안한 어댑터 연결을 추가한 후보는 0→1.
- **백팩:** 사전만 등록하면 백/팩의 잡음은 줄지만 배낭 문서는 연결되지 않아 0→0. 배낭 연결 추가는 0→1. 모델의 `compound_locked` 분류는 분해 관측 및 참조 `garbage_split`과 다르다.
- 두 후보는 각자 새 엔진에서 기존 36질의 게이트를 통과했다. 모든 질의의 전후 점수와 순위는 원자료에 있다. 동의 관계는 작성자가 명시한 전제이며 모델이 발견한 성과가 아니다.
- **티슈:** `[티슈,티슈]`는 전체 단어+2부분어 계약 위반이다. 원응답은 계속 차단한다. 원문에 존재하는 물티슈→물+티슈를 별도 수동 후보로 검사해 0→1, 게이트 회귀 없음. 이 후보는 새 20질의의 결합 설정에 포함하지 않았다.
- **A01:** 원문 어미까지 바꾼 인용은 복원하지 않았다. **A09:** 문서 제목을 본문처럼 인용한 실패를 유지했다. **A12:** 판단 불가 요약과 supported/unknown 상태의 모순을 임의 교정하지 않았다.
- **K001 지식 오류:** NR도 필터에서 제거된다는 과거 설명은 코드의 유지 품사와 달랐다. 현재 지식은 IC/NR을 구분한다. 옛 응답의 제공 문서 스냅샷은 변경하지 않았다.

## 설명 평가

`rubric.json`의 원인/인용 추적/의미 지지/수정 구조/수정 효과를 분리했다. 기존 생성 24건을 같은 원문 스냅샷으로 감사했다. 형식 결과는 지원 6/보류 12/차단 6으로 기존 재검증과 같았다.

기존 원인 라벨 9개에 대한 출력 family 일치는 문서 제공 7/9, 문서 제거 1/9이다. 보류도 불일치에 포함한 단순 라벨 일치로, 적절한 보류를 오진이라 단정하는 지표가 아니다. 원인이 실제로 식별 가능한 입력이었는지도 별도 판단해야 한다.

인용의 원문 존재와 의미 지지는 다르다. K001/K005 일반 설명만으로 백팩의 잘못된 family가 정당화되지 않으며, A08의 K019 회귀 경고도 표기 변형의 직접 증거는 아니다. 24건 모두 독립 인간 의미 평가 대기 상태다. Codex 분석 메모를 인간 확정 정답처럼 쓰지 않았다.
