# 추가 유료 평가 제안 — 미승인 미실행

현재 추가 호출 0회. 아래는 승인을 받기 전 실행할 수 없는 계획이다. 기존 24회 예산을 재사용하지 않는다.

- 모델: `gpt-5.4-mini-2026-03-17` (기존 실험과 동일; 실행 전 제공 여부·공식 요금 재확인).
- 대상: 고정 신규 사례 H01,H03,H05,H08,H09,H10,H11,H12,H21,H22,H23,H24. 원인 가설 7개, 건강 1개, 자료 부족/범위 밖 4개.
- 조건: 각 사례의 힌트/무힌트 쌍, 총 **24회**. 동일 모델·출력 상한·카탈로그·BM25 검색·프롬프트, 관찰 문장만 다르게 한다. 자동 재시도 0.
- 추정: 입력 1,500/출력 300토큰 가정. 기존 요금 입력 $0.75/백만, 출력 $4.50/백만을 적용하면 **약 $0.0594**. 실제 토큰 수에 따라 달라진다.
- 보수적 요청 예약 상한: $0.0125 × 24 = **$0.30**. 요청 바이트 상한 11,000+프로토콜 여유 512토큰, 출력 800토큰. 실패/불확실 요청도 예약에서 차감.
- 평가: 원인 분류(보류와 별도), 충분성별 보류율/잘못된 확신, 인용 추적, 독립 평가자의 의미 지지 점수, 패치 구조/회귀 효과. 인간 평가 비용은 위 API 추정에 포함되지 않는다.
- 기존 `evaluate_alba.py --live`는 종료 캠페인이므로 사용 불가. 새 캠페인·별도 원장·명시적 한도를 검토한 뒤 실행해야 한다.

이 계획을 작성했다는 사실은 승인이 아니다. 현재 보고서에는 모든 해당 생성 지표가 not_run이다.
