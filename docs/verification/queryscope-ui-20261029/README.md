# 검색 품질 검증 UI · 2026-10-29

요청: 질문형·대화형 제목 제거, 사례 중심 UI 개편, 기존 평가 자료 보존.

## 변경 범위
- 최신 화면 제목: 검색 품질 검증. 첫 화면: 사례 목록과 힌트 없음/있음 판정 비교.
- 질의/ID 검색, 평가 범위·판정 필터, 빈 결과, 이전/다음, 주소 해시를 이용한 선택 복원.
- 평가 요약과 실험 정보 분리, 키보드 탭 이동, 원문 인용·전체 응답·과거 판정 유지.
- 이전 6개 화면의 제목·섹션명과 공통 스타일 정리. 기존 URL/DOM/API 계약 유지.
- 원응답·JSON·승인·공급자·검색 로직·지원 문서는 변경하지 않음. 유료 모델 호출 0회.

## 현재 검증
- 제목·레이아웃의 기존 실패 3건을 먼저 확인하고 수정 후 3건 통과. 인코딩 검사 포함 4건 통과.
- 로컬 브라우저 메모리 렌더링: 실제 HTML/CSS/JS와 원본 JSON 사용. 48슬롯의 문맥·응답·인용·원자료 일치, 요약표 44셀, 필터·빈 결과·이전/다음·키보드 탭, 320/390/650/1024/1440px에서 문서 넘침 없음.
- 기존 검증 파일·웹 JSON 329개 바이트 보존. `preservation.json` 참조.
- `git diff --check`, JavaScript 구문 검사 통과.

로컬 일반 브라우저 HTTP 탐색은 관리 정책의 ERR_BLOCKED_BY_ADMINISTRATOR로 페이지 실행 전에 중단되어 네트워크 탐색 성공으로 계산하지 않음. 브라우저 보안 설정 변경 없이 인메모리 DOM 검사를 별도 수행. 실제 HTTP 경로·오류 응답·새로고침은 원격 브라우저 CI에서 추가 확인 대상.

로컬 전체 pytest는 kiwipiepy 미설치로 30개 수집 오류(모두 ModuleNotFoundError)를 기록함. 패키지 설치 경로에서 해당 버전을 확보할 수 없어 코드 오류로 처리하거나 검사를 삭제하지 않음. 전체 Python 회귀는 기존 Ubuntu/Windows CI로 검증 대상.

독립 리뷰어 도구가 없어 이 작업의 코드 검토는 같은 작성자의 재검토이며 독립적인 사람/AI 리뷰로 표현하지 않음. 원자료 불변, 안전한 textContent 렌더링, 실패 시 화면 숨김, 모바일 및 포커스 동작을 확인함.

원격 CI 및 공개 배포는 결과 확인 후 별도 기록.
