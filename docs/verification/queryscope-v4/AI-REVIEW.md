# 실제 v3 응답 24건: AI 사전 검토

**사람 평가 전 준비 자료입니다.** 아래는 AI가 원자료에서 확인한 관찰과 검토 질문입니다. 사람의 독립적인 판정·점수·검토자 이름을 작성하지 않았습니다. [검토 안내](HUMAN-REVIEW-GUIDE.md)의 다섯 축을 사람이 직접 판단해야 하며, 원래 H의 검토 필드는 pending/null 상태입니다.

자료: [R 실제 응답](../queryscope-v3/actual-api-v1/results.json), [A 이차 분석](../queryscope-v3/actual-api-audit-v1/audit.json), [H 사람 검토 기록](../queryscope-v3/actual-api-human-review.json), [사례](../queryscope-v3/cases.json), [카탈로그](../queryscope-v3/catalog.json), [기준](../queryscope-v3/rubric.json). 각 행의 R/A/H `/rows/n`은 0부터 시작하는 대응 위치입니다. `case_id`+`condition`과 `response_id`를 함께 대조합니다. 카탈로그 설명은 검토용 추가 자료이며 전체가 모델 입력에 있었다는 뜻은 아닙니다.

최초 판정은 supported 7·abstain 9·invalid 8입니다. 이는 상태·검사 결과로 의미적 정답 수가 아닙니다. [v4 새 적용 검사](run-v1/audit.json)는 별도 기록이며 아래 ‘과거 효과’는 최초·이차 분석의 효과를 가리킵니다. 인용 일치·가족 라벨 일치·패치 형식·검색 개선·의미 타당성을 합쳐 계산하지 않습니다.

‘최초 미측정’은 원래 판정에서 실행하지 않았다는 뜻입니다. ‘가상 적용’은 A가 원후보를 엔진 사본에 따로 적용한 사후 분석이며 차단 해제·실제 운영 반영이 아닙니다. 측정한 각 후보는 정답 있는 16질의와 기존 36질의에서 기록된 하락이 없지만, 유한한 작성 자료에서 개별 적용한 결과이며 의미 정답이나 결합 설정의 무회귀를 입증하지 않습니다.

## 판단할 때 놓치지 않을 구분

- **R 출처 실패:** R001/R002는 관찰, R005/R009/R010은 검색 결과에 실제 존재합니다. 없는 상품을 지어냈다는 뜻이 아니라 당시 허용한 운영 지식 본문 인용 출처가 아니라는 뜻입니다. T01 hint의 K004 문구 불일치는 별도 오류입니다.
- **T01의 대상 오류:** 관찰은 목공접착제의 색인 문제이나 패치는 접착제를 분해합니다. 문자열 재구성만 맞아도 대상이 틀리면 효과가 없습니다.
- **T15의 대응 부재:** 마이크로스코프는 카탈로그에 없고 R015는 현미경입니다. 일반 cross-script 원칙이 특정 번역을 입증하지 않습니다. no_hint 설명의 토큰 정보 누락 주장도 따로 검토합니다.
- **T16의 의미 미확인:** 박자/박자기의 자모 유사도는 명시적으로 unverified입니다. 작성 synonym_gap도 사람의 판정은 아닙니다. 의미와 기구명 대응을 확인해야 합니다.
- **정상 검색의 상태·인용:** T05/T09는 두 조건 모두 패치가 없고 설명은 정상 취지이나, no_hint는 supported이고 네 응답 모두 R 인용으로 차단됐습니다. 검색 장애나 패치 유발 손상으로 계산하지 않습니다.
- **보류의 이유:** T23/T24 no_hint는 범위 밖이라는 설명이 빠지고, hint는 이를 명시합니다. T17/T21도 한계를 정확히 설명했는지 확인해야 합니다. abstain 상태만으로 적절한 설명이 입증되지는 않습니다.
