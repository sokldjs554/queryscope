## 실행 중 보존과 중복 방지

실제 실행 함수 안에서 GitHub의 단일 원격 태그를 원자적으로 생성해야만 모델 호출 단계로 들어갑니다. 같은 실험의 태그가 이미 있으면 새 환경에서도 중단합니다. 기존 태그의 존재나 과거 영수증을 새 실행 허가로 사용하지 않습니다. 로컬 실행 표식과 예산 원장도 보존하며, 중간 실패 뒤 자동 재개는 하지 않습니다.

수신한 HTTP 본문은 해석·채점 전에 저장합니다. 응답이 불완전하거나 거부·잘못된 JSON·사용량 누락·HTTP 오류여도 수신 본문과 확인 가능한 메타데이터를 보존합니다. 수신하지 못한 응답은 만들어 넣지 않습니다. 요청 인증 헤더는 기록하지 않으며, 응답에 API 키가 그대로 반사되면 해당 값은 지우고 변경 사실과 해시를 남깁니다.

실제로 관측한 모델명이 고정 모델과 같은지, 응답 ID가 비어 있거나 중복되지 않는지 확인합니다. 연결 검증 실패는 `provenance_error`로 기록하고 채점 없이 중단합니다. API 실패는 모델의 정상 보류 응답과 구분합니다.
