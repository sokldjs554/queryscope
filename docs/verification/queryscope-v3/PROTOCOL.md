# QueryScope v3 사전 고정

2026-10-27 한국 시각. Codex가 작성한 합성16상품/24질의이다. v1과 v2는 이번 후속 개선에 사용하므로 개발자료이다. 과거 파일·정답·결과는 고치지 않는다. 이 새 파일/정답/기준/구성을 실행 전 Git과SHA로 고정한다.

이번 초점은 정상 형태소 변화와 실제 부분어 누락의 구분이다. 4개 복합어 전체형은 사용자 사전으로 통짜 색인을 강제한 **통제된 결함 시나리오**이며 자연 발생 분해 실패나 실고객 자료가 아니다. 부분어질의4개는 원문 존재·질의토큰색인누락·0건·재구성분해후정답복구의 사전조건을 검사한다. 정상8개는 상품명전체검색이 정답1위인지를 검사한다. 이 조건에 어긋나면 점수 계산을 중단하고 실패 자료를 남기며 정답을 자동 수정하지 않는다.

표기변형2/영한1/유의어1은 상품설명과 사용자 의도를 읽어 작성한 의미 정답이다. 관련문서2, 나머지0. 독립 인간 검토 전 확정적 의미 정답이 아니다. 분해오류 계열은 새자료에 없으므로 n=0으로 표시한다. 원인불명4, 운영근거부족2(양조건문서제거), 범위밖2를 포함한다. 정상/불명/부족/범위밖은 보류+무패치 계약이며 실제 보류 이유 적절성은 인간검토대기이다.

동일질의/상품/분석기/문서top3/본문400상한에서 관찰문장만 힌트유무로 바꾼다. 기존v2검색과 보완v3검색을 비교한다. 평가라벨은 검색기/모델입력에 넣지 않는다. 원인계열 일반원칙 hit@3/MRR, 정상8개의 잘못된 raw-substring-gap 신호수, 원문인용추적과 별도 의미판정을 보고한다. 16정답질의 nDCG/recall/P@5도 보고하고 없는8개는 제외한다. v3결과를 본 뒤 튜닝하지 않는다.

이전18상품/72상품과 ID/전체제목/질의문자열중복을 검사하고 어휘교집합을 보고한다. 휴대용 등 접미표현과 일부 물품개념·한국어상품도메인·운영지식·작성자를 공유하므로 완전독립/고객일반화가 아니다. 통제조건은 구성타당성 보강이며 생태타당성/인간의 의미검증을 대신하지 않는다.

실제LLM평가는 고정12개×2=24회 준비만 한다. 별도 승인 전 호출0회. v2준비물과 새준비물은 별도 식별/해시를 가지며 둘을 합쳐48회로 승인된 것처럼 취급하지 않는다. 원인분류/인용추적/의미적지지/수정구조/효과축을 유지한다. 테스트응답을 실제생성으로집계하지않고 모델답은null/not_run, 인간검토는pending으로남긴다.
