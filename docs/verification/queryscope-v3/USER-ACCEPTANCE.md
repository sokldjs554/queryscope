# 공개 데모 사용자 확인

2026-10-27 (한국 시각), 사용자가 대화에서 다음과 같이 보고했다.

> 데모 잘 접속되고 테스트도 다 해봤어

공개 데모에 접속했고 사용자의 수동 테스트를 마쳤다는 확인으로 기록한다. 사용 기기·브라우저·개별 URL·테스트 항목·측정값은 전달되지 않았으므로 특정 환경의 전체 체크리스트 통과로 확대하지 않는다.

Codex 환경의 HTTPS 접속은 프록시 CONNECT403으로 차단됐던 별도 기록을 유지한다. 로컬 자동 브라우저 검사, Render live 상태, 이번 사용자 직접 확인은 서로 다른 확인 근거이다.

이 보고는 모델 응답24건의 독립 인간 의미 평가나 공개 서비스의 장기 가용성·지연 측정이 아니다. [실제 API 평가와 남은 한계](ACTUAL-API.md)의 판정 및 미완료 항목은 그대로 유지한다. 추가 모델 호출이나 테스트 결과 수정은 하지 않았다.
