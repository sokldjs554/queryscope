## 재실행 방지와 원자료 보존

[일회성 워크플로](../../../.github/workflows/queryscope-v3-approved.yml)는 승인 파일이 main에 추가되는 push에만 반응한다. run_attempt1만 허용하며, 호출 전에 GitHub Git ref 생성 API로 `queryscope-v3-paid-<준비물SHA>` 태그를 원자적으로 생성한다. 기존 태그가 있으면 같은 커밋이어도 실패한다. HTTP오류도 실패 처리하고 자동 재시도하지 않는다. 로컬 체크아웃별 실행 표식·24회 예산 원장도 그대로 적용한다. 원격 표식을 임의로 삭제하거나 승인 파일을 바꿔 다시 실행하면 안 된다.

실제 응답은 채점 전에 저장한다. 실패·중단 시에도 원응답·오류·예산 영수증을 아티팩트와 `queryscope-v3-actual-api-results` 별도 브랜치에 보존한다. 결과를 확인한 뒤 main에 반영하며 이전 API24회, v1/v2/v3 오프라인 결과, 준비용null 응답을 새 모델 출력과 섞지 않는다. 정상·불명·근거부족·범위밖의 보류 계약 통과와 독립적인 의미적 적절성 판단도 구분한다.

독립 인간 의미 평가는 별도 수행 전까지 pending이다.

## 다섯 축과 이차 분석

원인 분류는 작성 라벨 일치, 인용은 제공 문서ID와 본문 위치 대조, 의미적 지지는 독립 인간 검토대기, 수정 구조는 IR 검증, 효과는 격리 엔진 전후 검색으로 나눴다. [인간 검토표](actual-api-human-review.json)는24개 모두 pending이다. 이번 자동/AI 분석을 독립 인간 평가로 세지 않았다.

[이차 오프라인 분석](actual-api-audit-v1/audit.json)은 실제 응답을 받은 **뒤** 인용별 실패와 차단된 후보의 잠재 효과를 분리해 분석한 추가 자료다. 최초24응답의 일차 판정이나 성공률을 바꾸지 않는다. 모델 호출0회이며 원자료 해시를 남겼다.

- 11응답의 raw 패치가 구조 검사를 통과했다. 구조가 성립해도 실제 대상 단어/의미가 맞는 것은 아니다.
- 일차에서 차단된 T01의 후보는 별도 가상 적용에서도 nDCG0→0, T02는0→1이었다. T02를 일차 성공으로 승격하지 않았다.
- 11개 raw 후보를 각각 새16정답질의와 기존36질의에서 별도로 비교했다. 측정한 nDCG/recall/P@5 하락0건이었다. 관련 문서 없는8개는 순위 평균에서 제외하며, 평가셋 밖 무회귀를 보장하지 않는다.
- 의미적 지지·동의어 적절성·보류 이유의 충분성은 여전히 독립 인간 검토가 필요하다. T16의 자모 유사성에 따른 오분류와 T15의 카탈로그에 없는 음차 연결은 다음 개선 대상으로 남긴다.
