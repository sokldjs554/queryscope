# v3 실제 API 평가 실행 기록

사용자는 v3의 `gpt-5.4-mini-2026-03-17`, 최대24회, 비용 예약 상한$0.30 계획을 승인했고 GitHub 시크릿을 연결해 재실행을 요청했다. [승인 기록](actual-api-approval.json)은 고정 준비물SHA `dfb4442ed8935b804cecfb5428ac374a765862c9ee96354cd8ddba556bdf3dfb`에만 적용한다. v2 준비물 실행과 추가 호출은 포함하지 않는다.

로컬 환경에는 API 키가 없으므로 GitHub Actions의 `OPENAI_API_KEY` 시크릿을 실행 단계에만 전달한다. 값은 로그·결과·Git 파일에 출력하지 않는다. 실제 API 주소는 기존 코드의 `https://api.openai.com/v1/responses`이며 프롬프트·스키마·출력 한도·고정 입력과 평가 기준은 바꾸지 않는다. 단가 입력$0.75/출력$4.50 per1M은 실행 전 공식 모델 페이지에서 재확인했다.

## 재실행 방지와 원자료 보존

[일회성 워크플로](../../../../.github/workflows/queryscope-v3-approved.yml)는 승인 파일이 main에 추가되는 push에만 반응한다. run_attempt1만 허용하며, 호출 전에 GitHub Git ref 생성 API로 `queryscope-v3-paid-<준비물SHA>` 태그를 원자적으로 생성한다. 기존 태그가 있으면 같은 커밋이어도 실패한다. HTTP오류도 실패 처리하고 자동 재시도하지 않는다. 로컬 체크아웃별 실행 표식·24회 예산 원장도 그대로 적용한다. 원격 표식을 임의로 삭제하거나 승인 파일을 바꿔 다시 실행하면 안 된다.

실제 응답은 채점 전에 저장한다. 실패·중단 시에도 원응답·오류·예산 영수증을 아티팩트와 `queryscope-v3-actual-api-results` 별도 브랜치에 보존한다. 결과를 확인한 뒤 main에 반영하며 이전 API24회, v1/v2/v3 오프라인 결과, 준비용null 응답을 새 모델 출력과 섞지 않는다. 정상·불명·근거부족·범위밖의 보류 계약 통과와 독립적인 의미적 적절성 판단도 구분한다.

실행 결과는 워크플로가 끝난 후 아래에 추가한다. 독립 인간 의미 평가는 별도 수행 전까지 pending이다.
