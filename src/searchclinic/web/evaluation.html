3. 판정의 범위
원인 분류: 저장 응답의 계열 라벨 비교와 별도 의미 검토. 인용: 원문 존재는 자동 검사, 이번 진단을 지지하는지는 사람 검토 필요. 수정안: 구조 검사와 실제 순위·회귀 효과를 분리합니다.
